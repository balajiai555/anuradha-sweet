# Anuradha Sweet and Restaurant

Official website for **Anuradha Sweet and Restaurant** (Anuradha Sweet House), located at Kishan Chowk, Kaptanganj, Kushinagar, Uttar Pradesh — 274301.

Serving authenticity, pure desi ghee traditional sweets, and fine vegetarian dining since **30th July, 2006**.

---

## 🌟 Highlights & Features
- **Frontend-Only Architecture:** Zero build tools required; runs seamlessly on GitHub Pages.
- **Brand Palette:** Luxury royal burgundy (`#7A1F2B`) and antique gold (`#C9A227`).
- **Smart WhatsApp Ordering (+91 9609657777):** Real-time interactive cart with formatted receipt generation for Home Delivery, Takeaway, and Dine-in.
- **Dynamic Portion / Weight Selection:** Select 250g, 500g, 1 Kg, or plate portions with live price recalculation.
- **Hero Carousel:** Highlighting traditional Desi Ghee Mithai, Anuradha Restaurant dining, and festive bulk gift hampers.
- **Local SEO & Google Maps:** Schema.org LocalBusiness JSON-LD markup and direct Google Maps embed for Kaptanganj, Kushinagar.
- **Designed & Developed:** [balajiailab.com](https://balajiailab.com)
